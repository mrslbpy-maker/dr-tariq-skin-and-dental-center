# Dr. Tariq Skin and Dental Center - Ultra-Premium Medical Platform

A high-performance, responsive, luxury light-mode clinical web platform for Dr. Tariq Skin and Dental Center, Lahore.

## Structure
- `index.html`: Semantic HTML5 structure with medical schema and accessible markup.
- `css/styles.css`: Full design system, light-mode palette (Alabaster, Medical Teal, Ice Cerulean), responsive layout.
- `js/main.js`: Interactive triage assessment, real-time operating hours evaluator, before/after slider, and 3-step booking engine with WhatsApp & .ics calendar generation.
- `assets/`: Scalable icons and visual elements.

## Key Features
1. **Dynamic Operating Hours Badge**: Calculates real-time clinic status for Asia/Karachi time.
2. **Dual-Domain Specialty Filter**: Instant filtering between Dermatology/Aesthetics and Dental Surgery.
3. **Interactive 30-Sec Clinical Triage**: Smart self-assessment quiz suggesting targeted protocols.
4. **Interactive Before/After Slider**: Draggable clinical transformation comparison.
5. **3-Step Clinical Reservation Engine**: Pakistani phone validation (+92), direct WhatsApp desk dispatch, and downloadable `.ics` iCalendar invites.
